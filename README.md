# PixelForge AI — Hackathon Image Editor

Local dev quick start:

1. Install dependencies

```bash
npm install
```

2. Run dev server

```bash
npm run dev
```

This project is built with Vite + React + TypeScript + Tailwind.

Features implemented:

- Image upload (drag & drop, file input, demo image)
- Layers (image, text, drawing)
- Basic drawing/eraser tool
- Text layers with editing
- Adjustments (brightness/contrast/saturation/hue)
- Simple crop tool
- AI Magic demo tools (auto-enhance, naive bg removal)
- Export (PNG/JPG/WebP)

More polishing and advanced AI integrations can be added as next steps.
