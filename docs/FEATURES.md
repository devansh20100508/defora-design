# Feature Documentation

## Image editing

### Upload and demo workflow

The app supports image upload using a file picker and a built-in demo image loader. The editor immediately loads the image into a canvas-based workspace.

### Adjustments

The editor includes sliders for:

- brightness
- contrast
- saturation
- exposure
- temperature
- sharpness
- blur

These are applied through the canvas rendering pipeline and can be reset at any time.

## Filters

Movie-like filters include:

- Original
- Cinematic
- Vintage
- Black & White
- Warm
- Cool
- Dramatic
- Faded
- High Contrast

## Layer system

The editor supports layered content comprised of:

- text
- shapes
- drawing strokes

Each layer can be toggled, reordered, aligned, and styled independently.

## Text editor

Text layers support:

- content editing
- font size adjustment
- color selection
- positioning on the canvas

## Shapes

Shape tools include:

- rectangle
- ellipse
- triangle
- diamond
- star
- line
- arrow

Each shape can have custom fill, stroke, size, and stroke width.

## Export

Export supports:

- PNG
- JPG
- WebP

This allows the final edited composition to be saved for use in social media, product design, and marketing content.

## AI demo features

The app includes a demo AI toolbar with placeholder actions such as auto-enhance, background cleanup inspiration, and style-driven editing experiences. These are not production-grade AI integrations but serve as a prototype UX layer.
